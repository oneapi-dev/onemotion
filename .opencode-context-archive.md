## Archived: 2026-10-20
### Architecture Decisions
- Split out of the OneAPI gateway repo (aiincs-clone) 2026-10-12; open source (MIT, Remotion license applies to >3-person companies).
- Depends on OneAPI: director calls ONEAPI_BASE_URL/chat/completions with the user's own key (header X-OneAPI-Key, kept in browser localStorage only); catalog facts from ONEAPI_CATALOG_URL.
- No DB, no billing: projects in localStorage (12 max). Export renders in the browser (WebCodecs); CLI fallback npm run render.
- Engine projects 3D in JS (no CSS perspective/radial-gradient/blend modes/z-index, since @remotion/web-renderer cannot draw them); glows are SVG radial images (engine/glow.tsx); draw order far to near.
- Director output is JSON only, checked by director/rules.ts (normalizePlan) and facts.ts (enforceFacts: numbers must come from brief/site/catalog).
2026-10-12: Hybrid Three.js (branch exp/three-room): floor/grid/dust are WebGL in engine/stage3d.tsx via @remotion/three; cards stay HTML.
Three camera = engine projector conjugated by y-flip (room y down -> three y up); canvas needs preserveDrawingBuffer (web-renderer drawImage copies it).
Floor shader fades to transparent so HTML room glows show through (no horizon line); card reflections dropped (cards float ~360px up, never visible in focus).
2026-10-13: Music = plan.score -> src/music/arrange (pure) -> render.ts native OfflineAudioContext, nodes made 1 s ahead via suspend.
Tone.js dropped: its always-on nodes made renders 3x slower. Track rendered in-page under delayRender (120 s timeout).
Same WAV blob feeds Player, web export and CLI. Cards land exactly on their scene's first beat.
2026-10-14: Bespoke (default mode) scenes run in-page via FilmHost (src/bespoke/host.ts), no sandbox iframe, open network; owner accepted key-exposure risk (see design spec "No sandbox").
